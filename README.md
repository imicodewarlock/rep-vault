# 🏋️‍♂️ RepVault

> *A personal workout companion built to replace messy notes and generic tracking apps with a clean, offline-first experience.*

---

## 🌟 Story Behind the Project

As someone passionate about fitness, I constantly found myself struggling with over-complicated workout apps filled with ads, paywalls, or cluttered interfaces. I simply wanted a fast, reliable tool to track my weights, time my rest intervals, and see my strength gains over time right from my phone.

So, I decided to code my own solution: **RepVault**.

I built RepVault to solve my personal gym needs—a distraction-free digital vault that securely stores every set, rep, and weight lifted, helping me stay focused and consistent with my fitness goals.

---

## ✨ Key Features

* **🏋️ Direct Workout Logging:** Quickly log exercise names, sets, reps, and weights lifted without unnecessary navigation.
* **⏱️ Integrated Rest Timer:** Stay on track during workouts with an automated, built-in rest timer to manage recovery between sets.
* **📈 Visual Progress Charts:** Track strength progression over time with interactive graphs that visualize weight gain trends.
* **🔒 100% Offline & Private:** All data remains strictly on your local device—no account creation, internet connection, or login required.
* **🌙 Dark Mode UI:** Designed with a sleek, low-glare dark layout optimized for gym environments.

## 🚀 How to Run the App

### Prerequisites
Make sure you have the following installed on your machine:
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable version)
* An Android/iOS Emulator or a physical device with Developer Options enabled.

### Quick Start Guide

1. **Clone the Repository**
   ```bash
   git clone https://github.com/imicodewarlock/rep-vault.git
   ```

2. **Navigate to the Project Directory**
   ```bash
   cd rep-vault
   ```

3. **Install Dependencies**
   ```bash
   flutter pub get
   ```

4. **Run the Application**
   ```bash
   flutter run
   ```

---

## 📱 How to Use RepVault

1. **Log an Exercise:** Tap the `+` button on the main screen to enter your exercise details (Name, Sets, Reps, Weight, and Rest Time).
2. **Start Your Rest Timer:** After completing a set, press the ▶️ button next to your exercise to trigger your rest timer.
3. **Analyze Progress:** Tap the chart icon in the upper right header to view your strength progression curve over time.
4. **Manage Entries:** Tap the trash icon on any exercise card to clear old or unwanted logs.
